# AI Generated Image Detection 🔍

A deep learning and web application system that classifies images as **REAL** (authentic camera photography) or **AI GENERATED** (synthetic images generated by models like Midjourney, Stable Diffusion, DALL-E, etc.).

---

## 📌 Architecture Overview

```
                          ┌───────────────────────────┐
                          │   React 19 + Vite (UI)    │
                          │   http://localhost:5173   │
                          └─────────────┬─────────────┘
                                        │ HTTP POST /predict (Multipart Image)
                                        ▼
                          ┌───────────────────────────┐
                          │     FastAPI Backend       │
                          │   http://localhost:8000   │
                          └─────────────┬─────────────┘
                                        │ Shared Preprocessing (No Double-Rescaling)
                                        ▼
                          ┌───────────────────────────┐
                          │  Keras 3 CNN Architecture │
                          │  - Random Augmentation    │
                          │  - Embedded Rescaling     │
                          │  - 4x Conv2D + BatchNorm  │
                          │  - Dense + Dropout + Sig  │
                          └───────────────────────────┘
```

## 🚀 Quick Start Guide

### 1. Prerequisites
- **Python 3.10+**
- **Node.js 18+** & **npm**

---

### 2. Python Environment Setup

Create and activate a virtual environment, then install requirements:

```bash
# Windows
python -m venv .venv
.venv\Scripts\activate

# Linux / macOS
python3 -m venv .venv
source .venv/bin/activate

# Install backend & model requirements
pip install -r backend/requirements.txt
```

---

### 3. CLI Prediction

Run predictions on any image file directly from the command line:

```bash
python scripts/predict.py test_image.png
```

**Output:**
```
RESULT: AI_GENERATED
CONFIDENCE: 87.39%
```

---

### 4. Running the FastAPI Backend

Start the FastAPI backend with hot-reload:

```bash
# Using uvicorn
python -m uvicorn backend.app:app --host 0.0.0.0 --port 8000 --reload
```

- **Health Check**: `GET http://localhost:8000/health`
- **Predict API**: `POST http://localhost:8000/predict` (multipart `file` upload, max 10MB)
- **Interactive Swagger Docs**: `http://localhost:8000/docs`

---

### 5. Running the React Frontend

Open a new terminal window:

```bash
cd frontend

# Install frontend dependencies (if not already installed)
npm install

# Copy environment template if needed
cp .env.example .env

# Start Vite development server
npm run dev
```

Open your browser at **http://localhost:5173**.

## 🧠 Model Training & Reproduction

To train or fine-tune the 128x128 CNN model:

1. **Prepare Dataset Structure**:
   Organize your dataset in `training/data/`:
   ```
   training/data/
   ├── train/
   │   ├── ai/        # AI-generated synthetic training images
   │   └── real/      # Real authentic photos
   └── val/
       ├── ai/        # AI-generated validation images
       └── real/      # Real validation photos
   ```

2. **Run Training**:
   ```bash
   python training/train.py --epochs 30 --batch-size 32 --lr 0.001
   ```

3. **Outputs**:
   - Best model saved to `model/ai_generated_image_detector.keras`.
   - Evaluation metrics (`accuracy`, `precision`, `recall`, `confusion_matrix`) saved to `training/metrics.json`.

For more details, see [`training/README.md`](training/README.md).

## 🔒 Verification & Error Handling
- **Double Normalization Prevention**: Normalization is embedded within the Keras model architecture (`Rescaling(1/255)`) — inference pipelines do not manually rescale.
- **Payload Validation**: The API validates that uploads are authentic image formats under 10MB before processing.
- **Dynamic Input Shape Handling**: Shared inference dynamically checks `model.input_shape` to support both 32x32 and 128x128 models automatically.
