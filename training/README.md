# Model Training Guide: AI Generated Image Detection

This directory contains the training pipeline to train and reproduce the Convolutional Neural Network (CNN) for classifying images as **REAL** or **AI GENERATED**.

---

## 1. Dataset Setup

The pipeline expects images organized in standard folder structure:

```
training/
└── data/
    ├── train/
    │   ├── ai/        # AI-generated training images (class index 0)
    │   └── real/      # Real photograph training images (class index 1)
    └── val/
        ├── ai/        # AI-generated validation images
        └── real/      # Real photograph validation images
```

### Recommended Public Datasets:
- **CIFAKE: Real vs AI Generated Synthetic Images** (Kaggle / Hugging Face)
- **Artifact Dataset / AI vs Real Art Dataset** (Kaggle)
- Any balanced dataset containing real photos and images generated by Midjourney, Stable Diffusion, DALL-E, etc.

---

## 2. Model Architecture & Pipeline Features

- **Input Dimensions**: `128 x 128 x 3` (RGB)
- **Built-in Augmentations & Preprocessing**:
  - `RandomFlip("horizontal")`
  - `RandomRotation(0.1)`
  - `RandomZoom(0.1)`
  - `Rescaling(1.0 / 255.0)` — embedded directly in the model so external inference code requires **no manual normalization**.
- **Convolutional Backbone (4 blocks)**:
  - Block 1: `Conv2D(32, 3x3)` + `BatchNorm` + `MaxPool2D(2x2)`
  - Block 2: `Conv2D(64, 3x3)` + `BatchNorm` + `MaxPool2D(2x2)`
  - Block 3: `Conv2D(128, 3x3)` + `BatchNorm` + `MaxPool2D(2x2)`
  - Block 4: `Conv2D(256, 3x3)` + `BatchNorm` + `MaxPool2D(2x2)`
- **Classifier Head**:
  - `Flatten` -> `Dense(128, relu)` -> `Dropout(0.5)` -> `Dense(1, sigmoid)`
- **Loss & Optimization**:
  - Optimizer: `Adam(learning_rate=0.001)`
  - Loss Function: `binary_crossentropy`
  - Output >= 0.5 indicates `REAL`, < 0.5 indicates `AI GENERATED`.
- **Callbacks**:
  - `EarlyStopping(monitor='val_loss', patience=6, restore_best_weights=True)`
  - `ModelCheckpoint(filepath='model/ai_generated_image_detector.keras', monitor='val_loss', save_best_only=True)`

---

## 3. How to Run Training

### Default Training:
```bash
# From the project root
python training/train.py
```

### Custom Training Arguments:
```bash
python training/train.py \
  --data-dir training/data \
  --epochs 30 \
  --batch-size 32 \
  --lr 0.001 \
  --model-path model/ai_generated_image_detector.keras \
  --metrics-path training/metrics.json
```

---

## 4. Output Artifacts

- **Trained Model**: Saved to `model/ai_generated_image_detector.keras` in Keras 3 format.
- **Evaluation Metrics**: Stored in `training/metrics.json` including:
  - Accuracy
  - Precision
  - Recall
  - Confusion Matrix `[[TN, FP], [FN, TP]]`
